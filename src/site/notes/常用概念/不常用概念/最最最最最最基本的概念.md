# 集合 set
 element of set: 集合的元素
 子集 subset:  $A \subseteq B$.
 真子集 proper subset:  $A\subsetneqq B$.
 空集 empty set:  $\emptyset$ $\varnothing$.
 并集 union of sets
 交集 intersection of sets
 笛卡尔积/卡氏积: Cartesian product of sets
# 类 class
类分为集合(set)和真类(proper class)或称为固有类.
具有某种性质的全体.
集合的全体、序数的全体都是真类.

# 范畴 category
+ 对象构成类
+ 不同元素对儿之间的态射集交是空集
+ 态射的复合满足 ① 结合律 ② 恒等态射
## 加法范畴 additive category
+ ① 有零对象
+ ② 存在有限直和
+ ③ 两个对象之间的态射是加法交换群, 且满足左右分配律
## 阿贝尔范畴 abelian category
+ 是加法范畴
+ 每个态射都有核与余核
+ 态射的像与余像是同构的


 $\operatorname{mod}A$ 有限生成模范畴
