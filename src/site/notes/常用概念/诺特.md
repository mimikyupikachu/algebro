# Artin-Algebra
+ 一个环 $R$ 是诺特环如果它**每个理想都是有限生成的**.
+ 等价刻画:不存在环 $R$ 的理想的无限严格升链 $I_1< I_2<\cdots$.
+ 实例: 主理想整环当然都是诺特环. 因为它的理想都是有一个元素生成的, 当然就是诺特环. 所以 $\mathbb{Z}$, $\mathbb{Z}[\mathrm{i }]$, $F[x]$ 都是主理想整环都是诺特环.
